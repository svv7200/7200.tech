# 7200.tech — IT-аутсорсинг

Сайт-визитка моего IT-аутсорсинг сервиса. Помогаю бизнесу и частным лицам решать технические задачи: от настройки серверов и сетевой инфраструктуры до разработки и поддержки веб-проектов.

## Стек

- HTML5 / CSS3
- [Materialize CSS](https://materializecss.com/) — UI-фреймворк
- Кастомные шрифты: Mr. Amazing, Roboto

## Структура проекта

```
├── index.html          # Главная страница
└── assets/
    ├── css/            # Стили (Materialize + кастомные)
    ├── fonts/          # Шрифты
    └── files/          # Дополнительные файлы
```

## Деплой

Сайт развёрнут на VPS (Германия) под управлением nginx. Xray (VLESS+TLS) обслуживает порт 443 и проксирует браузерный трафик на nginx через fallback-механизм.

- Домен: [7200.tech](https://7200.tech)
- Веб-сервер: nginx 1.22
- Сертификат: Let's Encrypt
