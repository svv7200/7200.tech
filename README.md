## 🖥️ Инфраструктура VPS

**Сервер:** Германия, Debian 12  
**Панель управления VPN:** [3x-ui](https://github.com/MHSanaei/3x-ui) v3.2.8 (xray-core 26.6.1)

### Архитектура

```
Клиент
  │
  ├─► :443 TCP  ──► xray (VLESS + XTLS-Vision)
  │                   └─► fallback ──► nginx ──► сайт 7200.tech
  │
  ├─► :4443 UDP ──► xray (Hysteria2 + QUIC)
  │
  └─► :51820 UDP ──► xray (WireGuard)
```

Nginx слушает на внутреннем порту и отдаёт сайт-заглушку.  
Порт `:80` делает редирект на HTTPS.  
Браузерный трафик на `:443` xray передаёт в nginx через fallback — для антидетекта.

- Домен: [7200.tech](https://7200.tech)
- Веб-сервер: nginx 1.22
- Сертификат: Let's Encrypt (wildcard `*.7200.tech`)

## 🔒 VLESS + XTLS-Vision

Основной протокол. Работает на порту `443/TCP` поверх TLS — выглядит как обычный HTTPS.

| Параметр | Значение |
|----------|----------|
| Протокол | VLESS |
| Адрес | `7200.tech` |
| Порт | `443` |
| TLS | Включён |
| Flow | `xtls-rprx-vision` |
| Fingerprint | `chrome` |
| SNI | `7200.tech` |

**Поддерживаемые клиенты:** Hiddify, v2rayN, NekoBox, Karing, Streisand (iOS)

## ⚡ Hysteria2

Протокол на базе QUIC (UDP). Быстрее VLESS на нестабильных соединениях, особенно на мобильных сетях.

| Параметр | Значение |
|----------|----------|
| Протокол | Hysteria2 |
| Адрес | `7200.tech` |
| Порт | `4443` |
| TLS | Включён |
| ALPN | `h3` |
| Fingerprint | `chrome` |
| SNI | `7200.tech` |

**Формат ссылки:**
```
hysteria2://<password>@7200.tech:4443?alpn=h3&fp=chrome&security=tls&sni=7200.tech
```

**Поддерживаемые клиенты:** Hiddify, Karing, NekoBox, v2rayN 7+

> **Важно:** протокол работает по UDP — порт 4443 должен быть открыт для UDP в файрволе.

## 🛡️ WireGuard

Протокол для постоянного подключения уровня сети. Идеально подходит для роутеров — весь трафик домашней сети идёт через VPN без настройки на каждом устройстве.

| Параметр | Значение |
|----------|----------|
| Порт | `51820/UDP` |
| Адресация клиентов | `10.0.0.2/32`, `10.0.0.3/32`, ... |
| MTU | 1420 |
| Keepalive | 25 сек |

### Добавить нового клиента

1. Сгенерировать пару ключей на сервере:
   ```bash
   CLIENT_PRIV=$(wg genkey)
   CLIENT_PUB=$(echo $CLIENT_PRIV | wg pubkey)
   ```

2. В панели 3x-ui добавить нового пира в инбаунд WireGuard:
   - `publicKey` — публичный ключ клиента
   - `allowedIPs` — следующий свободный IP, например `10.0.0.3/32`

3. Передать клиенту конфиг-файл `client.conf`:
   ```ini
   [Interface]
   PrivateKey = <приватный ключ клиента>
   Address = 10.0.0.X/32
   DNS = 1.1.1.1

   [Peer]
   PublicKey = <публичный ключ сервера>
   Endpoint = <домен>:51820
   AllowedIPs = 0.0.0.0/0
   PersistentKeepalive = 25
   ```

### Подключение на роутере TP-Link

1. Войти в веб-интерфейс роутера
2. Перейти: **VPN → WireGuard → Import config**
3. Загрузить файл `client.conf`
4. Нажать **Enable**

**Поддерживаемые устройства:** TP-Link с поддержкой WireGuard, OpenWrt, Mikrotik 7+, Keenetic

## 📦 Подписка (Subscription)

```
https://7200.tech:2096/sub/<sub_id>
```

Ссылку для каждого пользователя можно скопировать в панели 3x-ui в разделе клиента.
